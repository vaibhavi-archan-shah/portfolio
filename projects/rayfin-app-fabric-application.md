## Rayfin App Fabric Analytics Application

## Project Overview

A Microsoft Rayfin app developed in Fabric for Tickets analytics using React, TypeScript, and a Power BI semantic model.

The application provides a modern, filter-driven user experience for exploring quality records and exporting controlled analytical outputs.

## Business Problem

Business users required a cleaner application-style interface for reviewing tickets data instead of navigating a conventional analytical report.

The solution also needed:

- Dynamic filtering
- Date-range selection
- Semantic-model integration
- Excel export
- User identification

## Solution Architecture

Source Data -> Fabric Pipeline -> Fabric Lakehouse -> Power BI Semantic Model -> Fabric Rayfin Application

## Technologies Used
- Microsoft Fabric
- Power BI Semantic Models
- Fabric Apps
- Agentic Development
- DAX
- ExcelJS
- Git
- Azure DevOps

## Key Features
- Semantic-model-backed application data
- Dynamic last-30-day date range
- Multi-select filters
- Application-side sorting and pagination
- Configurable rows per page
- User authentication context
- Excel export
- Responsive application interface
